# University Database Management System
An undergraduate database course project implemented with MySQL.

## Project Overview
This database system is designed to manage university-related information. It implements core database operations including creating tables, inserting, querying, updating and deleting student and department records. The project demonstrates relational database design, primary & foreign key constraints, and basic SQL statement development.

## Technologies
- MySQL
- Structured Query Language (SQL)

## Features
- Relational table design for students, departments and courses
- Multi-condition data query
- Data insertion, modification and deletion
- Integrity constraint setting
